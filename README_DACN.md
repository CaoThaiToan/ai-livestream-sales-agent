# AI Livestream Sales Agent

Đồ án: Nghiên cứu, xây dựng và phát triển AI Agents hỗ trợ
tự động hóa trong hoạt động Marketing.

## Thành viên
- Toản: quản lý project, Git, avatar và tích hợp hệ thống.
- Quỳnh: dữ liệu sản phẩm, agent tư vấn và đánh giá.

## Nền tảng
Dự án phát triển dựa trên LiveTalking:
https://github.com/lipku/LiveTalking

Giữ nguyên lịch sử mã nguồn và giấy phép gốc.
Các phần nhóm phát triển sẽ được ghi nhận theo từng phiên bản.

## Tiến độ
- Đã thiết lập môi trường và kiểm tra tính toán GPU.
- Đã chạy avatar mẫu và đọc văn bản tiếng Việt.
- Tiếp theo: tích hợp tư vấn sản phẩm.

## Dữ liệu và cấu hình
- sales_data/: dữ liệu sản phẩm và chính sách của đồ án.
- models/ và data/avatars/: tải riêng theo hướng dẫn LiveTalking.
- Không đưa API key hoặc file .env thật lên Git.
